# Ephemeris Satellite Viewer

## Goal

An enterprise-grade, spatiotemporal satellite pass visualization application optimized for high-performance trajectory querying and real-time spatial intersection calculations.

## Architecture & Stack

- **Frontend:** React (Vite, TypeScript, MapLibre GL JS, TailwindCSS, Zustand, React Query)
- **Backend:** Node.js (Express, TypeScript)
- **Analytical Datastore:** DuckDB with Native Spatial Extension
- **Containerization:** Docker / Docker Compose

## Development Status

- **Current State:** Phase 1 (Core Infrastructure & Workspace Foundation)
